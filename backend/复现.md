### 步骤 3.1: ApiResponse.java——统一响应格式

**来源：手写**
**含义**：所有接口返回的数据都包在这个格式里，前端只需要解析一种 JSON 格式。

```java
package com.mytext.learningassistant.common;

import com.fasterxml.jackson.annotation.JsonInclude;

/**
 * 统一响应格式。
 * 成功：{"code":0, "message":"ok", "data":{实际数据}}
 * 失败：{"code":400, "message":"用户名已存在", "data":null}
 */
@JsonInclude(JsonInclude.Include.NON_NULL)
public record ApiResponse<T>(int code, String message, T data) {

    /** 创建成功响应 */
    public static <T> ApiResponse<T> ok(T data) {
        return new ApiResponse<>(0, "ok", data);
    }

    /** 创建失败响应 */
    public static <T> ApiResponse<T> error(int code, String message) {
        return new ApiResponse<>(code, message, null);
    }
}
```

> **大白话**：`record` 是 Java 16+ 的语法，自动帮你生成构造方法、getter、equals、toString。比以前写 class 简单很多。

### 步骤 3.2: BusinessException.java——自定义业务异常

**来源：手写**
**含义**：当业务逻辑出错时（比如"用户名已存在"），抛出这个异常，全局异常处理器会捕获它并返回标准错误格式。

```java
package com.mytext.learningassistant.common;

/**
 * 业务异常。code 对应 HTTP 状态码（如 400、401、404、429）。
 */
public class BusinessException extends RuntimeException {
    private final int code;

    public BusinessException(int code, String message) {
        super(message);
        this.code = code;
    }

    public int getCode() {
        return code;
    }
}
```

### 步骤 3.3: GlobalExceptionHandler.java——全局异常处理

**来源：手写**
**含义**：不管哪里抛异常，最终都会被这个类捕获，统一转成 `ApiResponse` 格式返回前端。这样前端永远收到的是 `{"code":..., "message":..., "data":...}` 格式。

```java
package com.mytext.learningassistant.common;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

@RestControllerAdvice   // 标记：拦截所有 Controller 的异常
public class GlobalExceptionHandler {

    private static final Logger log = LoggerFactory.getLogger(GlobalExceptionHandler.class);

    /** 捕获业务异常，返回对应的错误码和消息 */
    @ExceptionHandler(BusinessException.class)
    public ResponseEntity<ApiResponse<Void>> handleBusiness(BusinessException e) {
        return ResponseEntity
            .status(e.getCode())
            .body(ApiResponse.error(e.getCode(), e.getMessage()));
    }

    /** 兜底：捕获所有未预期的异常 */
    @ExceptionHandler(Exception.class)
    public ResponseEntity<ApiResponse<Void>> handleUnexpected(Exception e) {
        log.error("Unexpected error", e);
        return ResponseEntity
            .status(HttpStatus.INTERNAL_SERVER_ERROR)
            .body(ApiResponse.error(500, "服务器内部错误"));
    }
}
```

### 步骤 4.1: 创建数据库表——V1 迁移脚本

```sql
CREATE TABLE sys_user (

    username VARCHAR(64) NOT NULL,

    password_hash VARCHAR(128) NOT NULL,
```

### 步骤 4.4: UserEntity.java——用户表映射

**来源：手写**
**含义**：告诉 JPA "这张 Java 类对应数据库里的哪张表，每个字段对应哪一列"。JPA 会自动帮你做 Java 对象 ↔ 数据库记录的转换。

```java
package com.mytext.learningassistant.user;

import jakarta.persistence.*;
import java.time.LocalDateTime;

@Entity                              // 标记：这是一个数据库表映射
@Table(name = "sys_user")           // 对应 sys_user 表
public class UserEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, unique = true, length = 64)
    private String username;

    @Column(length = 128)
    private String email;

    @Column(name = "password_hash", nullable = false, length = 128)
    private String passwordHash;

    @Column(nullable = false, length = 64)
    private String nickname;

    @Column(columnDefinition = "TEXT")
    private String avatar;

    @Enumerated(EnumType.STRING)      // 存数据库时存字符串（"ADMIN"），不是数字
    @Column(nullable = false)
    private UserRole role;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private UserStatus status;

    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;

    @PrePersist                       // 保存前自动填充时间
    void onCreate() {
        createdAt = LocalDateTime.now();
        updatedAt = LocalDateTime.now();
    }

    @PreUpdate                        // 更新前自动刷新时间
    void onUpdate() {
        updatedAt = LocalDateTime.now();
    }

    // ===== getter/setter =====
    // 在 IDEA 里：把光标放在类里面 → 按 Alt+Insert → 选 Getter and Setter → 全选 → 确定
    // 以下为手写版本（两种方式都行）

    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }
    public String getUsername() { return username; }
    public void setUsername(String username) { this.username = username; }
    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }
    public String getPasswordHash() { return passwordHash; }
    public void setPasswordHash(String passwordHash) { this.passwordHash = passwordHash; }
    public String getNickname() { return nickname; }
    public void setNickname(String nickname) { this.nickname = nickname; }
    public String getAvatar() { return avatar; }
    public void setAvatar(String avatar) { this.avatar = avatar; }
    public UserRole getRole() { return role; }
    public void setRole(UserRole role) { this.role = role; }
    public UserStatus getStatus() { return status; }
    public void setStatus(UserStatus status) { this.status = status; }
    public LocalDateTime getCreatedAt() { return createdAt; }
    public LocalDateTime getUpdatedAt() { return updatedAt; }
}
```

### 步骤 4.4.1: DefaultAdminInitializer.java（手写）

> **含义**：应用启动时自动创建默认管理员账号。需要在配置里显式开启。

```java
package com.mytext.learningassistant.user;

import com.mytext.learningassistant.auth.PasswordHasher;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.boot.ApplicationArguments;
import org.springframework.boot.ApplicationRunner;
import org.springframework.stereotype.Component;

@Component
public class DefaultAdminInitializer implements ApplicationRunner {
    private final UserRepository userRepository;
    private final PasswordHasher passwordHasher;
    private final boolean bootstrapEnabled;
    private final String username;
    private final String password;
    private final String nickname;

    public DefaultAdminInitializer(UserRepository userRepository, PasswordHasher passwordHasher,
        @Value("${app.admin.bootstrap-enabled:false}") boolean bootstrapEnabled,
        @Value("${app.admin.username:admin}") String username,
        @Value("${app.admin.password:}") String password,
        @Value("${app.admin.nickname:admin}") String nickname) {
        this.userRepository = userRepository;
        this.passwordHasher = passwordHasher;
        this.bootstrapEnabled = bootstrapEnabled;
        this.username = username == null || username.isBlank() ? "admin" : username.trim();
        this.password = password == null ? "" : password.trim();
        this.nickname = nickname == null || nickname.isBlank() ? this.username : nickname.trim();
    }

    @Override
    public void run(ApplicationArguments args) {
        if (!bootstrapEnabled) return;
        if (password.length() < 12) throw new IllegalStateException("admin password must be >= 12 chars");
        if (userRepository.findByUsername(username).isPresent()) return;

        UserEntity admin = new UserEntity();
        admin.setUsername(username);
        admin.setPasswordHash(passwordHasher.hash(password));
        admin.setNickname(nickname);
        admin.setRole(UserRole.ADMIN);
        admin.setStatus(UserStatus.ACTIVE);
        userRepository.save(admin);
    }
}
```

### 步骤 4.5: UserRepository.java——数据库操作接口

**来源：手写**

```java
package com.mytext.learningassistant.user;

import org.springframework.data.jpa.repository.JpaRepository;
```

### 步骤 5.4: TokenService.java——Token 生成和解析

**来源：手写**
**含义**：登录成功后生成一个加密字符串（Token），前端以后每次请求都带上这个 Token，服务器用它来识别你是谁。

```java
package com.mytext.learningassistant.auth;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.security.Keys;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import javax.crypto.SecretKey;
import java.util.Base64;
import java.util.Date;

@Service
public class TokenService {

    private final SecretKey key;
    private final long expiryMillis;

    public TokenService(
        @Value("${app.auth.secret:mySecretKey123456789012345678901234567890}") String secret,
        @Value("${app.auth.expiry-hours:72}") long expiryHours
    ) {
        // 用密钥字符串生成加密用的 Key
        this.key = Keys.hmacShaKeyFor(
            Base64.getDecoder().decode(Base64.getEncoder().encodeToString(secret.getBytes()))
        );
        this.expiryMillis = expiryHours * 3600 * 1000;
    }

    /** 生成 Token：把 userId 和 tokenVersion 加密进去 */
    public String generateToken(long userId, int tokenVersion) {
        Date now = new Date();
        return Jwts.builder()
            .setSubject(String.valueOf(userId))
            .claim("tokenVersion", tokenVersion)
            .setIssuedAt(now)
            .setExpiration(new Date(now.getTime() + expiryMillis))
            .signWith(key)
            .compact();
    }

    /** 解析 Token：解密出 userId 和 tokenVersion */
    public TokenClaims parseClaims(String token) {
        Claims claims = Jwts.parserBuilder()
            .setSigningKey(key)
            .build()
            .parseClaimsJws(token)
            .getBody();
        return new TokenClaims(
            Long.parseLong(claims.getSubject()),
            claims.get("tokenVersion", Integer.class)
        );
    }

    /** Token 里解密出来的数据 */
    public record TokenClaims(long userId, int tokenVersion) {}
}
```

> **大白话**：
> - `generateToken`：把用户ID加密成一串字符（类似 `eyJhbGci...`），前端存起来
> - `parseClaims`：把那串字符解密回来，得到用户ID
> - `tokenVersion`：用来让旧Token失效（用户改密码后，旧Token里的版本号就对不上了）

### 步骤 5.4.1: PasswordHasher.java（手写）

```java
package com.mytext.learningassistant.auth;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.Base64;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.stereotype.Component;

@Component
public class PasswordHasher {
    private final BCryptPasswordEncoder bcrypt = new BCryptPasswordEncoder(12);

    public String hash(String rawPassword) {
        return bcrypt.encode(rawPassword);
    }

    public boolean matches(String rawPassword, String storedValue) {
        if (rawPassword == null || storedValue == null || storedValue.isBlank()) return false;
        if (storedValue.startsWith("$2")) {
            try { return bcrypt.matches(rawPassword, storedValue); }
            catch (RuntimeException e) { return false; }
        }
        return matchesLegacySha256(rawPassword, storedValue);
    }

    public boolean needsRehash(String storedValue) {
        return storedValue == null || !storedValue.startsWith("$2") || bcrypt.upgradeEncoding(storedValue);
    }

    private boolean matchesLegacySha256(String rawPassword, String storedValue) {
        String[] parts = storedValue.split(":", 2);
        if (parts.length != 2) return false;
        try {
            byte[] salt = Base64.getDecoder().decode(parts[0]);
            byte[] expected = Base64.getDecoder().decode(parts[1]);
            MessageDigest md = MessageDigest.getInstance("SHA-256");
            md.update(salt);
            return MessageDigest.isEqual(expected, md.digest(rawPassword.getBytes(StandardCharsets.UTF_8)));
        } catch (Exception e) { return false; }
    }
}
```

### 步骤 5.5: AuthInterceptor.java——登录拦截器

**来源：手写**
**含义**：每个请求到达 Controller 之前，先经过这个拦截器。它检查 Token，确认你是谁，然后把 userId 塞到 request 里，后面的 Controller 就能直接用。

```java
package com.mytext.learningassistant.auth;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.mytext.learningassistant.common.ApiResponse;
import com.mytext.learningassistant.user.UserEntity;
import com.mytext.learningassistant.user.UserRepository;
import com.mytext.learningassistant.user.UserStatus;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpMethod;
import org.springframework.http.HttpStatus;
import org.springframework.http.MediaType;
import org.springframework.stereotype.Component;
import org.springframework.web.servlet.HandlerInterceptor;
import java.util.Set;

@Component
public class AuthInterceptor implements HandlerInterceptor {

    // 不需要登录就能访问的接口
    private static final Set<String> PUBLIC_PATHS = Set.of(
        "/api/health",
        "/api/auth/register",
        "/api/auth/login",
        "/api/auth/check-username"
    );

    private final TokenService tokenService;
    private final UserRepository userRepository;
    private final ObjectMapper objectMapper;

    public AuthInterceptor(TokenService tokenService, UserRepository userRepository, ObjectMapper objectMapper) {
        this.tokenService = tokenService;
        this.userRepository = userRepository;
        this.objectMapper = objectMapper;
    }

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        String path = request.getRequestURI();

        // 公开路径和OPTIONS请求直接放行
        if (HttpMethod.OPTIONS.matches(request.getMethod()) || PUBLIC_PATHS.contains(path)) {
            return true;
        }

        // 从请求头提取 Token
        String header = request.getHeader(HttpHeaders.AUTHORIZATION);
        if (header == null || !header.startsWith("Bearer ")) {
            return send401(response);
        }

        try {
            String token = header.substring(7).trim();
            TokenService.TokenClaims claims = tokenService.parseClaims(token);

            // 查数据库确认用户存在且正常
            UserEntity user = userRepository.findById(claims.userId()).orElse(null);
            if (user == null || user.getStatus() != UserStatus.ACTIVE) {
                return send401(response);
            }

            // 验证通过！把 userId 塞进 request，Controller 里就能用 @RequestAttribute 拿到
            request.setAttribute("currentUserId", user.getId());
            request.setAttribute("currentUserRole", user.getRole().name());
            return true;
        } catch (Exception e) {
            return send401(response);
        }
    }

    private boolean send401(HttpServletResponse response) throws Exception {
        response.setStatus(HttpStatus.UNAUTHORIZED.value());
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        objectMapper.writeValue(response.getWriter(), ApiResponse.error(401, "未登录"));
        return false;   // false = 拦截，请求不会到达 Controller
    }
}
```

### 步骤 5.6: AuthService.java——注册和登录逻辑

**来源：手写**
**含义**：处理注册和登录的业务逻辑。Controller 调用这个类的方法。

```java
package com.mytext.learningassistant.auth;

import com.mytext.learningassistant.common.BusinessException;
import com.mytext.learningassistant.user.UserEntity;
import com.mytext.learningassistant.user.UserRepository;
import com.mytext.learningassistant.user.UserRole;
import com.mytext.learningassistant.user.UserStatus;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.stereotype.Service;

@Service
public class AuthService {

    private final UserRepository userRepository;
    private final TokenService tokenService;
    private final BCryptPasswordEncoder encoder = new BCryptPasswordEncoder();

    public AuthService(UserRepository userRepository, TokenService tokenService) {
        this.userRepository = userRepository;
        this.tokenService = tokenService;
    }

    /** 注册：创建新用户，返回 Token */
    public LoginResponse register(RegisterRequest request) {
        // 检查用户名是否已存在
        if (userRepository.findByUsername(request.username()).isPresent()) {
            throw new BusinessException(409, "用户名已存在");
        }
        // 创建用户
        UserEntity user = new UserEntity();
        user.setUsername(request.username());
        user.setPasswordHash(encoder.encode(request.password()));  // 密码加密存储
        user.setNickname(request.nickname());
        user.setRole(UserRole.STUDENT);
        user.setStatus(UserStatus.ACTIVE);
        userRepository.save(user);

        // 生成 Token 返回
        String token = tokenService.generateToken(user.getId(), 0);
        return new LoginResponse(token, user.getId(), user.getUsername(), user.getNickname(), user.getRole().name());
    }

    /** 登录：验证用户名密码，返回 Token */
    public LoginResponse login(LoginRequest request) {
        UserEntity user = userRepository.findByUsername(request.username())
            .orElseThrow(() -> new BusinessException(401, "用户名或密码错误"));

        if (!encoder.matches(request.password(), user.getPasswordHash())) {
            throw new BusinessException(401, "用户名或密码错误");
        }
        if (user.getStatus() != UserStatus.ACTIVE) {
            throw new BusinessException(403, "账号已被禁用");
        }

        String token = tokenService.generateToken(user.getId(), user.getTokenVersion());
        return new LoginResponse(token, user.getId(), user.getUsername(), user.getNickname(), user.getRole().name());
    }
}
```

### 步骤 8.5: MaterialFileTicketService.java（手写）

> **含义**：为 iframe/img 等无法带 Cookie 的场景生成一次性下载令牌。

```java
package com.mytext.learningassistant.material;
import java.security.SecureRandom;
import java.time.Instant;
import java.util.Base64;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import org.springframework.stereotype.Service;

@Service
public class MaterialFileTicketService {
    private static final long TICKET_TTL_MILLIS = 30 * 60 * 1000L;
    private final SecureRandom secureRandom = new SecureRandom();
    private final Map<String, Ticket> tickets = new ConcurrentHashMap<>();

    public MaterialFileTicketResponse create(long ownerId, long materialId) {
        cleanupExpired();
        byte[] bytes = new byte[24];
        secureRandom.nextBytes(bytes);
        String token = Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
        long expiresAt = Instant.now().toEpochMilli() + TICKET_TTL_MILLIS;
        tickets.put(token, new Ticket(ownerId, materialId, expiresAt));
        return new MaterialFileTicketResponse(token, "/api/materials/" + materialId + "/file?ticket=" + token, expiresAt);
    }

    public Long validate(String token, long materialId) {
        if (token == null || token.isBlank()) return null;
        Ticket ticket = tickets.get(token);
        if (ticket == null || ticket.materialId() != materialId || ticket.expiresAt() < Instant.now().toEpochMilli()) {
            tickets.remove(token);
            return null;
        }
        return ticket.ownerId();
    }

    private void cleanupExpired() {
        long now = Instant.now().toEpochMilli();
        tickets.entrySet().removeIf(entry -> entry.getValue().expiresAt() < now);
    }
    private record Ticket(long ownerId, long materialId, long expiresAt) {}
}
```

**文本分块核心算法**（简化版）：
```java
private static final int CHUNK_MIN = 300;
private static final int CHUNK_MAX = 800;
private static final int CHUNK_OVERLAP = 120;

private List<MaterialChunkEntity> splitTextIntoChunks(Long materialId, String text) {
    List<MaterialChunkEntity> chunks = new ArrayList<>();
    // 1. 按双换行分成段落
    String[] paragraphs = text.split("\\n\\n+");
    StringBuilder buffer = new StringBuilder();
    int index = 0;

    for (String paragraph : paragraphs) {
        buffer.append(paragraph).append("\n\n");
        // 2. 缓冲区达到最小长度时，按句子边界切分
        if (buffer.length() >= CHUNK_MIN) {
            String chunkText = buffer.toString().trim();
            if (chunkText.length() > CHUNK_MAX) {
                // 在 CHUNK_MAX 附近找句号位置切分
                int splitPos = findSentenceBoundary(chunkText, CHUNK_MAX);
                String first = chunkText.substring(0, splitPos).trim();
                String second = chunkText.substring(splitPos).trim();
                chunks.add(createChunk(materialId, index++, first));
                buffer = new StringBuilder(second).append("\n\n");
            } else {
                chunks.add(createChunk(materialId, index++, chunkText));
                buffer.setLength(0);
            }
        }
    }
    // 3. 处理剩余内容
    if (!buffer.toString().isBlank()) {
        chunks.add(createChunk(materialId, index, buffer.toString().trim()));
    }
    return chunks;
}
```

```java
        @RequestAttribute("currentUserId") long currentUserId,

            // 4. 发送 sources 和 done 事件

            sendEvent(outputStream, "done", Map.of("questionId", result.questionId(), "conversationId", result.conversationId()));
```

### 步骤 14.2.1: InMemoryShortTermStateStore.java（手写，约200行）

> **含义**：基于 JVM 内存的短期状态存储，开发环境用。带过期时间的 ConcurrentHashMap。

```java
package com.mytext.learningassistant.security;
import java.time.Clock;
import java.time.Duration;
import java.util.Iterator;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.ConcurrentMap;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.stereotype.Component;

@Component
@ConditionalOnProperty(prefix = "app.redis", name = "enabled", havingValue = "false", matchIfMissing = true)
public class InMemoryShortTermStateStore implements ShortTermStateStore {
    private static final long CLEANUP_INTERVAL_MILLIS = 300_000L;
    private final ConcurrentMap<String, Entry> entries = new ConcurrentHashMap<>();
    private final Clock clock = Clock.systemUTC();
    private volatile long lastCleanupAt;

    public void put(String key, String value, Duration ttl) {
        long now = clock.millis();
        maybeCleanup(now);
        entries.put(key, new Entry(value, now + Math.max(1L, ttl.toMillis())));
    }
    public String get(String key) {
        long now = clock.millis();
        maybeCleanup(now);
        Entry entry = entries.get(key);
        if (entry == null || entry.expiresAt <= now) { entries.remove(key, entry); return null; }
        return entry.value;
    }
    public String getAndDelete(String key) {
        long now = clock.millis();
        Entry entry = entries.remove(key);
        return (entry == null || entry.expiresAt <= now) ? null : entry.value;
    }
    public void delete(String key) { entries.remove(key); }
    public long incrementAndGet(String key, Duration ttl) {
        long now = clock.millis();
        Entry entry = entries.compute(key, (ignored, current) -> {
            if (current == null || current.expiresAt <= now) return new Entry("1", now + Math.max(1L, ttl.toMillis()));
            long count = parseLong(current.value) + 1L;
            return new Entry(Long.toString(count), current.expiresAt);
        });
        return parseLong(entry.value);
    }
    private long parseLong(String value) { try { return Long.parseLong(value); } catch (Exception e) { return 0L; } }
    private void maybeCleanup(long now) {
        if (now - lastCleanupAt < CLEANUP_INTERVAL_MILLIS) return;
        lastCleanupAt = now;
        Iterator<Map.Entry<String, Entry>> it = entries.entrySet().iterator();
        while (it.hasNext()) { if (it.next().getValue().expiresAt <= now) it.remove(); }
    }
    private record Entry(String value, long expiresAt) {}
}
```

### 步骤 14.2.3: OutboundUrlGuard.java（手写，约330行）

> **含义**：防止 SSRF 攻击，验证出站 URL 不是内网地址。校验协议、主机名、IP地址、DNS解析结果。

```java
package com.mytext.learningassistant.security;
import java.net.*;
import java.util.Locale;
import com.mytext.learningassistant.common.BusinessException;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

@Service
public class OutboundUrlGuard {
    private final boolean allowPrivateNetwork;
    private final boolean resolveHosts;

    public OutboundUrlGuard(
        @Value("${app.security.outbound.allow-private-network:false}") boolean allowPrivateNetwork,
        @Value("${app.security.outbound.resolve-hosts:true}") boolean resolveHosts) {
        this.allowPrivateNetwork = allowPrivateNetwork;
        this.resolveHosts = resolveHosts;
    }

    public URI requirePublicHttpUrl(String value, boolean httpsOnly) {
        if (value == null || value.isBlank()) throw new BusinessException(400, "URL不能为空");
        try { return requirePublicHttpUrl(URI.create(value.trim()), httpsOnly); }
        catch (IllegalArgumentException e) { throw new BusinessException(400, "URL格式不正确"); }
    }

    public URI requirePublicHttpUrl(URI uri, boolean httpsOnly) {
        String scheme = uri.getScheme() == null ? "" : uri.getScheme().toLowerCase(Locale.ROOT);
        if (httpsOnly && !"https".equals(scheme)) throw new BusinessException(400, "URL必须使用HTTPS");
        if (!"http".equals(scheme) && !"https".equals(scheme)) throw new BusinessException(400, "URL仅支持HTTP/HTTPS");
        String host = uri.getHost();
        if (host == null || host.isBlank()) throw new BusinessException(400, "URL缺少主机名");
        validateHost(host);
        return uri;
    }

    private void validateHost(String host) {
        String h = host.startsWith("[") && host.endsWith("]") ? host.substring(1, host.length()-1) : host;
        h = h.toLowerCase(Locale.ROOT);
        if (allowPrivateNetwork) return;
        if ("localhost".equals(h) || h.endsWith(".localhost") || "metadata.google.internal".equals(h))
            throw new BusinessException(400, "不允许访问本机或内网地址");
        if (h.matches("\\d+")) throw new BusinessException(400, "不允许访问内网地址");
        if (h.matches("\\d{1,3}(?:\\.\\d{1,3}){3}") || h.contains(":")) {
            try { if (isBlocked(InetAddress.getByName(h))) throw new BusinessException(400, "不允许访问内网地址"); }
            catch (UnknownHostException e) { throw new BusinessException(400, "URL主机无法解析"); }
        }
        if (!resolveHosts) return;
        try {
            for (InetAddress addr : InetAddress.getAllByName(h))
                if (isBlocked(addr)) throw new BusinessException(400, "不允许访问内网地址");
        } catch (UnknownHostException e) { throw new BusinessException(400, "URL主机无法解析"); }
    }

    private boolean isBlocked(InetAddress a) {
        return a.isAnyLocalAddress() || a.isLoopbackAddress() || a.isLinkLocalAddress()
            || a.isSiteLocalAddress() || a.isMulticastAddress() || isBlockedIpv4(a) || isBlockedIpv6(a);
    }
    private boolean isBlockedIpv4(InetAddress a) {
        if (!(a instanceof Inet4Address)) return false;
        byte[] b = a.getAddress(); int f = b[0]&0xff, s = b[1]&0xff;
        return f==0 || f==10 || f==127 || (f==100&&s>=64&&s<=127) || (f==169&&s==254)
            || (f==172&&s>=16&&s<=31) || (f==192&&s==168) || (f==198&&(s==18||s==19)) || f>=224;
    }
    private boolean isBlockedIpv6(InetAddress a) {
        if (!(a instanceof Inet6Address)) return false;
        int f = a.getAddress()[0] & 0xff;
        return f==0 || (f&0xfe)==0xfc || f==0xfe;
    }
}
```

```java
    private static final Duration WINDOW_TTL = Duration.ofSeconds(75);
    private final ShortTermStateStore stateStore;
    private final int loginPerMinute;
    private final int registerPerMinute;
    private final int ragChatPerMinute;

    public RateLimitService(ShortTermStateStore stateStore,
        @Value("${app.security.rate-limit.login-per-minute:10}") int loginPerMinute, ...) {

        this.loginPerMinute = loginPerMinute;

    public void checkRagChat(String identity) { check("rag-chat", identity, ragChatPerMinute); }

    private void check(String bucket, String identity, int limit) {
        if (limit <= 0) return;

        String n = identity == null ? "" : identity.trim().toLowerCase();
        return n.isBlank() ? "anonymous" : n;
    }
```

```java
// SystemLogEntity.java — 系统日志表
package com.mytext.learningassistant.admin;
import jakarta.persistence.*;
import java.time.LocalDateTime;
import java.time.ZoneId;

@Entity @Table(name = "system_log")
public class SystemLogEntity {
    private static final ZoneId BEIJING_ZONE = ZoneId.of("Asia/Shanghai");
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private Long id;
    private Long actorUserId;
    private String action;        // "UPDATE_USER_ROLE" 等
    private String targetType;    // "USER" 等
    private Long targetId;
    @Column(columnDefinition = "TEXT") private String detail;
    private LocalDateTime createdAt;
    @PrePersist void onCreate() { if (createdAt == null) createdAt = LocalDateTime.now(BEIJING_ZONE); }
    // getter/setter 省略
}

// SystemLogRepository.java
package com.mytext.learningassistant.admin;
import org.springframework.data.jpa.repository.JpaRepository;
import java.util.List;
public interface SystemLogRepository extends JpaRepository<SystemLogEntity, Long> {
```
