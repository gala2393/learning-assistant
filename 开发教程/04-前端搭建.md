## 四、路由配置

### 4.1 什么是 React Router？

React Router 是 React 的路由库，根据 URL 显示不同的页面，实现"单页应用"（SPA）。

### 4.2 路由表

export const router = createBrowserRouter([
  { path: '/', element: <Navigate to="/login" replace /> },

### 4.3 路由守卫（ProtectedRoute）

```tsx
function ProtectedRoute({ children, requireAdmin = false }) {
  const { isAuthenticated, isAdmin, isLoading } = useAuth()

  if (isLoading) return <LoadingSpinner />
  if (!isAuthenticated) return <Navigate to="/login" />
  if (requireAdmin && !isAdmin) return <Navigate to="/workspace/chat" />

  return children
}
```

```tsx
// src/context/AuthContext.tsx
function AuthProvider({ children }) {
  const [session, setSession] = useState(() => {
    const saved = localStorage.getItem('learning-assistant.frontend.session')
    return saved ? JSON.parse(saved) : null
  })

  // 启动时验证 Token 是否有效
  useEffect(() => {
    if (session?.token) {
      api.get('/auth/me').catch(() => setSession(null))
    }
  }, [])

  const login = async (username, password) => {
    const data = await api.post('/auth/login', { username, password })
    setSession(data)
    localStorage.setItem('learning-assistant.frontend.session', JSON.stringify(data))
  }

  return (
    <AuthContext.Provider value={{ session, isAuthenticated: !!session, isAdmin: session?.user.role === 'ADMIN', login, logout, ... }}>
      {children}
    </AuthContext.Provider>
  )
}
```

### 5.3 External Store — 聊天状态

聊天功能需要高性能的状态更新（流式输出时每秒更新多次），用 React 状态会导致不必要的重渲染。

> 📄 **文件位置**：`frontend/src/lib/chat-session.ts`

```typescript
// src/lib/chat-session.ts
// 外部 Store 模式（类似 Redux，但更轻量）

type ChatSessionSnapshot = {
  messages: ChatMessage[]
  streaming: boolean
  sources: RagSource[]
  // ...
}

let state: ChatSessionSnapshot = { messages: [], streaming: false, sources: [] }
const listeners = new Set<() => void>()

// 通知所有订阅者
function emit() { listeners.forEach(fn => fn()) }

// React 通过 useSyncExternalStore 订阅
export function subscribeChatSession(listener: () => void) {
  listeners.add(listener)
  return () => listeners.delete(listener)
}

export function getChatSessionSnapshot() { return state }

// 更新状态
export function updateChatSession(partial: Partial<ChatSessionSnapshot>) {
  state = { ...state, ...partial }
  emit()  // 触发 React 重新渲染
}
```

**在组件中使用**：

```tsx
function ChatPage() {
  const chat = useSyncExternalStore(subscribeChatSession, getChatSessionSnapshot)
  // chat.messages, chat.streaming, chat.sources ...
}
```

**当前聊天 Store 保存了哪些东西？**

| 字段 | 作用 |
|------|------|
| `messages` | 聊天线程里展示的 user/assistant 消息 |
| `conversationId` | 多轮对话 ID，后续问题会继续归入同一历史会话 |
| `conversationHistory` | 发送给后端的最近几轮上下文 |
| `images` | 待发送图片，来自上传或粘贴截图 |
| `temporaryMaterial` | 智能问答里的临时资料上下文 |
| `materialId/chunkId` | 资料问答或阅读器跳转时绑定的资料位置 |
| `streaming` | 是否正在接收 SSE 流式回答 |

**持久化策略**：

- `sessionStorage` 保存当前标签页刷新后的即时恢复。
- `localStorage` 保存一份草稿备份，避免标签页关闭后完全丢失。
- `learning-assistant.chat.conversation-archive` 按 `conversationId` 归档完整前端会话，用于历史会话回显图片和临时资料附件。
- 临时资料正文很长时会截断到 2 万字再写入浏览器存储，避免超过 localStorage 容量。

## 六、API 层设计

### 6.1 Axios 封装

> 📄 **文件位置**：`frontend/src/lib/axios.ts`

```typescript
// src/lib/axios.ts
import axios from 'axios'

export const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE || '/api',
  timeout: 60_000,
})

// 请求拦截器：自动附加 Token
api.interceptors.request.use((config) => {
  const session = JSON.parse(localStorage.getItem('learning-assistant.frontend.session') || 'null')
  if (session?.token) {
    config.headers.Authorization = `Bearer ${session.token}`
  }
  return config
})

// 响应拦截器：统一解包
api.interceptors.response.use(
  (response) => {
    const { code, message, data } = response.data
    if (code !== 0) throw new Error(message)
    return data
  },
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('learning-assistant.frontend.session')
      window.location.href = '/login'
    }
    if (!error.response) {
      // 网络错误（后端没启动）
      throw new Error('后端服务未启动，请检查后端是否正常运行')
    }
    throw error
  }
)
```

## 七、流式聊天（SSE）

### 什么是 SSE？

SSE（Server-Sent Events）是服务器向浏览器推送数据的技术。和 WebSocket 不同，SSE 是单向的（服务器→浏览器），适合"AI 打字机"效果。

### 聊天附件前端流转

聊天输入框现在同时支持图片和文件附件，前端按文件类型拆分处理：

```
用户选择/粘贴附件
  ├─ 图片 image/*
  │   ├─ ChatComposer 压缩到最大边长 1280px
  │   ├─ 存入 chat-session.images
  │   └─ 发送时进入 ChatRequest.images
  │
  └─ 文档 PDF/DOCX/PPTX/TXT/MD/HTML
      ├─ GENERAL 通用模式：调用 uploadTemporaryMaterial()
      │   ├─ 后端同步抽取文本
      │   ├─ 返回 TemporaryMaterial
      │   ├─ ChatAttachmentCards 展示附件卡片
      │   └─ 发送时作为 temporaryMaterial 上下文
      │
      └─ MATERIAL 资料模式：调用 uploadMaterialInChunks()
          ├─ 大文件分片上传
          ├─ 后端后台解析
          └─ 成功后进入资料库，可用于资料问答
```

临时资料和持久资料的 UI 也不同：

- 临时资料显示在输入框上方的 `ChatAttachmentCards`，可打开 `TemporaryMaterialPreviewDialog` 看抽取文本。
- 持久资料上传使用 `MaterialUploadForm`，成功后会刷新资料列表并绑定到资料问答模式。
- 图片缩略图可在发送前或历史消息中通过 `ImagePreviewDialog` 放大、缩小、重置。

### 实现方式

> 📄 **文件位置**：`frontend/src/api/rag.ts`（`chatStream` 函数）

```typescript
// src/api/rag.ts 的 chatStream 函数

export function chatStream(payload, callbacks) {
  const { onSources, onChunk, onDone, onError } = callbacks
  const controller = new AbortController()  // 用于取消请求

  fetch('/api/rag/chat/stream', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${getToken()}`,
    },
    body: JSON.stringify(payload),
    signal: controller.signal,
  }).then(async (response) => {
    const reader = response.body.getReader()
    const decoder = new TextDecoder()
    let buffer = ''

    while (true) {
      const { done, value } = await reader.read()
      if (done) break

      buffer += decoder.decode(value, { stream: true })
      const lines = buffer.split('\n')
      buffer = lines.pop()  // 保留不完整的行

      for (const line of lines) {
        if (line.startsWith('event: sources')) {
          // 下一行是数据
        } else if (line.startsWith('event: chunk')) {
          // 流式文本增量
        } else if (line.startsWith('event: done')) {
          onDone?.(JSON.parse(line.slice(6)))
        } else if (line.startsWith('data: ')) {
          const data = JSON.parse(line.slice(6))
          // 根据前一个 event 类型处理
        }
      }
    }
  })

  return { abort: () => controller.abort() }
}
```

### 11.3 AuthContext — 认证状态管理

> 📄 **文件位置**：`frontend/src/context/AuthContext.tsx`

```tsx
import { createContext, useContext, useState, useEffect, ReactNode } from "react";
import { api } from "../lib/axios";

interface AuthUser {
  id: number;
  username: string;
  nickname: string;
  avatar: string;
  role: string;
  canAccessAdminConsole: boolean;
  visibleRoutes: string[];
  permissions: string[];
}

interface AuthSession {
  token: string;
  user: AuthUser;
}

interface AuthContextType {
  session: AuthSession | null;
  isAuthenticated: boolean;
  isAdmin: boolean;
  isLoading: boolean;
  login: (username: string, password: string) => Promise<void>;
  logout: () => void;
}

const STORAGE_KEY = "learning-assistant.frontend.session";

const AuthContext = createContext<AuthContextType>(null!);

export function AuthProvider({ children }: { children: ReactNode }) {
  const [session, setSession] = useState<AuthSession | null>(() => {
    const saved = localStorage.getItem(STORAGE_KEY);
    return saved ? JSON.parse(saved) : null;
  });
  const [isLoading, setIsLoading] = useState(true);

  // 启动时验证 Token 是否有效
  useEffect(() => {
    if (session?.token) {
      api.get("/auth/me")
        .catch(() => {
          setSession(null);
          localStorage.removeItem(STORAGE_KEY);
        })
        .finally(() => setIsLoading(false));
    } else {
      setIsLoading(false);
    }
  }, []);

  const login = async (username: string, password: string) => {
    const data = await api.post("/auth/login", { username, password });
    setSession(data);
    localStorage.setItem(STORAGE_KEY, JSON.stringify(data));
  };

  const logout = () => {
    setSession(null);
    localStorage.removeItem(STORAGE_KEY);
  };

  return (
    <AuthContext.Provider value={{
      session,
      isAuthenticated: !!session,
      isAdmin: session?.user.role === "ADMIN",
      isLoading,
      login,
      logout,
    }}>
      {children}
    </AuthContext.Provider>
  );
}

export const useAuth = () => useContext(AuthContext);
```

import axios from "axios";

export const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE || "/api",
  timeout: 60_000,

// 请求拦截器：自动附加 Token
api.interceptors.request.use((config) => {
  const session = JSON.parse(localStorage.getItem("learning-assistant.frontend.session") || "null");
  if (session?.token) {
    config.headers.Authorization = `Bearer ${session.token}`;
  }
  return config;
});

// 响应拦截器：统一解包
api.interceptors.response.use(
  (response) => {
    const { code, message, data } = response.data;
    if (code !== 0) throw new Error(message);
    return data;
  },
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem("learning-assistant.frontend.session");
      window.location.href = "/login";
    }
    if (!error.response) {
      throw new Error("后端服务未启动，请检查后端是否正常运行");
    }
    throw error;
  }
);

### 11.9 api/rag.ts — RAG 问答 API（流式）

> 📄 **文件位置**：`frontend/src/api/rag.ts`

```typescript
import { api } from "../lib/axios";

interface StreamCallbacks {
  onSources?: (sources: any[]) => void;
  onChunk?: (delta: string) => void;
  onDone?: (result: any) => void;
  onError?: (error: string) => void;
}

export function chatStream(payload: any, callbacks: StreamCallbacks) {
  const { onSources, onChunk, onDone, onError } = callbacks;
  const controller = new AbortController();

  fetch(`${import.meta.env.VITE_API_BASE || "/api"}/rag/chat/stream`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${JSON.parse(localStorage.getItem("learning-assistant.frontend.session") || "{}").token}`,
    },
    body: JSON.stringify(payload),
    signal: controller.signal,
  }).then(async (response) => {
    const reader = response.body!.getReader();
    const decoder = new TextDecoder();
    let buffer = "";

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      buffer += decoder.decode(value, { stream: true });
      const lines = buffer.split("\n");
      buffer = lines.pop() || "";

      for (const line of lines) {
        if (line.startsWith("event: sources")) {
          // 下一行 data 是来源列表
        } else if (line.startsWith("event: chunk")) {
          // 下一行 data 是文本增量
        } else if (line.startsWith("data: ")) {
          const data = JSON.parse(line.slice(6));
          if (data.sources) onSources?.(data.sources);
          if (data.delta) onChunk?.(data.delta);
          if (data.questionId) onDone?.(data);
        }
      }
    }
  }).catch((err) => {
    if (err.name !== "AbortError") onError?.(err.message);
  });

  return { abort: () => controller.abort() };
}
```
